# Security Log Analyzer & Intrusion Detection Dashboard

### 1. Project Overview

The Security Log Analyzer & Intrusion Detection Dashboard is a Python-based cybersecurity project designed to analyze security logs and detect suspicious 
login activities. It identifies patterns such as multiple failed login attempts and successful logins following repeated failures, helping highlight potential 
unauthorized access.

### 2. Technologies & Features

The project uses Python, Flask, SQLite, HTML, CSS, and JavaScript. Its features include log parsing, rule-based intrusion detection, risk classification, 
security alert storage, duplicate alert prevention, a web-based dashboard, alert statistics, and security report generation.

### 3. Results & Learning Outcomes

The system was tested using sample security logs and successfully generated security alerts with different risk levels. The dashboard displays detected 
events and provides a centralized view of security alerts. This project demonstrates practical skills in security log analysis, intrusion detection, 
incident monitoring, database integration, Python programming, and dashboard development. It is intended for educational purposes and authorized security monitoring.
